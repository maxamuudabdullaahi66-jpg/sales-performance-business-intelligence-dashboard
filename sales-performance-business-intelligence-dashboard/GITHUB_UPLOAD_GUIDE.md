# GitHub Upload Guide

## Option 1 — GitHub website

1. Sign in to GitHub.
2. Create a new repository named:
   `sales-performance-business-intelligence-dashboard`
3. Keep the repository public if you want employers/recruiters to view it.
4. Upload all files from this folder.
5. Commit the files.
6. Open the repository and confirm that `README.md` appears on the front page.

## Option 2 — Git command line

```bash
git init
git add .
git commit -m "Initial Sales Performance BI project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/sales-performance-business-intelligence-dashboard.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.
